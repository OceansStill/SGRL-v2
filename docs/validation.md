# 实现验证记录

此文件记录工程检查，不记录基准效果。SGRL-v2 尚未进行 GPU 训练或 Sudoku / Maze / ARC 全量评测。

## 源码与实现范围

- 官方上游：`https://github.com/nilskiKonjIzDunava/fprm`。
- 下载分支：`main`；基线提交：`b291252387b2656d7a7bc2719d9317e6d812b283`。
- 方法参考：[method_reference.md](method_reference.md)，来自此前用户提供的方案讨论。
- 复用上游层、两层共享核心、数据构建/读取及可选 ARC 汇总器；SGRL 的训练和评测使用独立入口。
- 恢复阶段按方法原式采用无动量梯度下降与回溯。训练基座使用 AdamW，题目稀疏嵌入沿用上游 SignSGD。
- 有限教师初始化、投影梯度探针、真实任务损失不增条件、敏感度阈值与 checkpoint 格式是显式实现选择；默认值未调参。

## CPU 检查

环境：Python 3.11，PyTorch `2.11.0+cu129`；检查时屏蔽 CUDA，并限制为一个 CPU 线程。

```bash
CUDA_VISIBLE_DEVICES="" TORCHDYNAMO_DISABLE=1 OMP_NUM_THREADS=1 \
  python -m unittest discover -s tests -v
```

测试使用小尺寸真实 Transformer 和具有已知行为的合成状态映射，检查：

- 自然 anchor 不依赖标签，筛选仅要求当前错误与末端窗口全错；中途正确不自动排除。
- Padding 不计入整题正确率、任务损失和状态度量。
- 修复桥端点属于后续路径，几何检查不要求端点与自身分离。
- 冻结教师参数时仍可对输入隐藏状态反传；搜索不修改原模型，交付状态已 detach。
- 合成可恢复系统中能找到合格教师，并经过真实学生损失与更新后检查接受更新。
- 无教师样本继续训练；回溯失败或检查异常会恢复原参数。
- EMA 不因被拒的参数更新推进。
- 稀疏嵌入缓存经过设备/类型转移后仍是优化器可处理的 leaf tensor。
- 多个评测上限来自同一轨迹；正确变错会被计数。
- 采样游标跨采样块恢复；小型训练的中断/恢复与连续训练参数及 EMA 一致。

2026-11-16（北京时间）执行结果：

- 在集群提交节点的既有 Python 环境执行，15 项 CPU 回归测试全部通过。
- 独立命令行检查通过：配置/元数据 dry-run、基础训练、加载 EMA 开始恢复训练、独立 EMA 配对评测。数据为临时生成的 12 个合成样本，测试完成后删除临时目录；没有把这些样本当作 Sudoku 或 ARC 成绩。
- 对新增 11 个 Python 文件完成 AST 解析；README 与本文件的本地链接目标均存在；`git diff --check` 通过。

单元测试通过不说明真实网络上的教师成功率、GPU 精度模式、显存、速度或任务泛化。

## 尚未验证的部分

- GPU 上的教师优化、长窗口显存和耗时；bfloat16 对严格验收条件的影响。
- 真正任务上的教师覆盖率、被接受更新率，以及准确率改善。
- ARC 全量反增强/投票流程与不同预处理数据集的端到端结果。
- 多进程训练未实现；入口明确拒绝多 rank 启动。
- 原版 FPRM checkpoint 的结构转换未提供；恢复阶段要求本实现 checkpoint。

上述开发验证没有提交 Slurm 作业，也没有运行模型性能实验。公开发布不改变这些验证范围。
