**SGRL-v2的核心，是把训练时找到的修复过程，学进同一个共享递归网络。** 推理时，模型照常反复运行这个网络；希望它遇到不理想状态后，能够自己产生有用的后续更新。

它的主要创新位置在**训练原则与递归动力学的耦合**。当前版本没有独立纠错网络，也不使用扩散、能量函数或历史槽库。

下面按完整流程展开。这里介绍的是已定义的研究方案，尚无任务实验结果。

---

**1．它具体想解决什么问题？**

设原来的递归模型为：

\[
z_{t+1}=T_\theta(z_t;x).
\]

其中，\(x\)是输入表示，\(z_t\)是第\(t\)次loop的隐藏状态。

假设模型进入了一个错误状态\(a\)，继续运行仍然答错。训练时，我们可能找到一条修复路径：

\[
a=q_0\longrightarrow q_1\longrightarrow\cdots\longrightarrow q_m,
\]

而从\(q_m\)开始，原模型继续计算能够得到正确答案。

最直接的做法是训练：

\[
T_\theta(q_j;x)\approx q_{j+1}.
\]

但只学这些点对，存在三个问题：

| 问题 | 为什么会发生 | SGRL-v2的处理 |
|---|---|---|
| **目标冲突** | 两个阶段的隐藏状态很接近，却要求产生不同后继；共享网络没有阶段标签可用 | 构造彼此分离的状态邻域 |
| **误差积累** | 学生实际到达的是\(q_j+\delta\)，而非精确的教师点\(q_j\) | 在整个邻域训练修正偏差的更新 |
| **有效续算被破坏** | 为了学会前半段修复而更新参数，却改变了后半段原本正确的计算 | 在候选参数更新后，检查有效续算是否保留 |

**SGRL-v2把这三个问题作为同一个训练问题处理。**

**2．推理时的网络是什么？**

忽略batch维度，定义：

\[
x=E(X)\in\mathbb R^{N\times d},
\qquad
z_t\in\mathbb R^{N\times d},
\]

\[
D(z)=Wz+b.
\]

在恢复训练阶段：

- 冻结输入编码器\(E\)；
- 冻结输出头\(W,b\)；
- 更新共享递归映射的参数\(\theta\)。

当前候选选定的FPRM计算单元是：**两个Transformer block、pre-RMSNorm、无卷积、无额外输出归一化**。

将两个block展开为四个子层，attention与SwiGLU交替：

\[
\boxed{
h^0=\alpha_2\odot z+\beta_2\odot x
}
\]

\[
\boxed{
h^\ell
=
\alpha_1\odot h^{\ell-1}
+
\beta_1\odot
f_{\theta,\ell}
\!\left(\operatorname{RMSNorm}(h^{\ell-1})\right),
\quad \ell=1,\ldots,4
}
\]

系数为：

\[
\alpha_i=\operatorname{sigmoid}(a_i),
\]

\[
\beta_2=1-\alpha_2\odot\alpha_1^4,
\qquad
\beta_1=
\frac{\beta_2\odot(1-\alpha_1)}
{1-\alpha_1^4+10^{-5}}.
\]

于是：

\[
\boxed{
T_\theta(z;x)=h^4.
}
\]

推理始终执行：

\[
\boxed{
z_{t+1}=T_\theta(z_t;x),
\qquad
\widehat y=\arg\max D(z_K).
}
\]

**一次推理内，各个loop的参数完全相同。** 参数只在训练的批次之间更新。

当前版本使用固定\(K\)次loop，替换FPOPT外层控制，不继承FPOPT的停止与收敛结论。

**3．训练首先收集模型自己产生的失败状态**

在一个训练批次开始时，保存当前参数快照：

\[
\bar\theta=\theta.
\]

用这个快照正常运行模型，得到某个中间状态：

\[
\boxed{
a=T_{\bar\theta}^{\,t}(z_0;x).
}
\]

这里的\(a\)来自模型自己的计算，没有注入正确答案。

设总预算为\(K\)，末端检查窗口长度为\(S\)，定义：

\[
H=K-t-S.
\]

从\(a\)继续运行旧模型，检查第\(H,\ldots,H+S\)步的输出。

如果：

- \(a\)当前预测错误；
- 原模型在这个末端窗口内仍然全部答错；

就把它作为尝试构造修复路径的对象。

**这只是“在规定预算内没有恢复”，不表示它永远无法恢复。**

正确样本、搜索失败样本仍保留普通任务监督，不会被丢弃。

**4．训练时寻找一座“桥”，连接到有效的后续计算**

我们希望构造：

\[
\underbrace{a=q_0\rightarrow q_1\rightarrow\cdots\rightarrow q_m}_{\text{待学入共享网络的修复桥}}
\rightarrow
\underbrace{w_1\rightarrow w_2\rightarrow\cdots}_{\text{旧模型实际执行的后续计算}}.
\]

其中：

\[
w_0=q_m,
\qquad
w_{k+1}=T_{\bar\theta}(w_k;x).
\]

这里有一个重要约束：

**不是随便造一个输出正确的隐藏向量，而是要求桥的端点交给原模型后，真实续算在规定末端窗口内保持正确。**

桥的中间读出可以暂时变差；我们不要求每一步都更像最终答案。

为了让桥具有明确的前进方向，使用：

\[
\boxed{
q_j=a+\frac jm v+P_vU_j,
\qquad j=0,\ldots,m
}
\]

其中：

\[
P_vU_j
=
U_j-
v\frac{\langle v,U_j\rangle_M}{\|v\|_M^2},
\qquad U_0=U_m=0.
\]

含义是：

- \(v\)：从失败状态到桥端点的总体位移；
- \(U_j\)：允许路径弯曲的自由变量；
- \(P_vU_j\)：去掉沿\(v\)的分量，让弯曲主要发生在横向。

\(\|\cdot\|_M\)表示只在有效位置上计算、按坐标平均的范数。

由于横向部分与\(v\)正交：

\[
\|q_j-q_i\|_M
\ge
\frac{|j-i|}{m}\|v\|_M.
\]

这使我们能够约束不同阶段之间保持足够距离。

**5．为什么要学“走廊”，而不只学路径上的点？**

围绕每个桥点定义一个邻域：

\[
\mathcal B_j
=
\{z:\|z-q_j\|_M\le r_B\}.
\]

围绕有效后续计算的状态定义：

\[
\mathcal V_k
=
\{z:\|z-w_k\|_M\le r_S\},
\qquad r_S\ge r_B.
\]

构造时要求桥邻域彼此分离，并与后续计算邻域保持间隙。例如：

\[
\|v\|_M\ge m(r_B+r_S+g),
\]

\[
\|q_j-w_k\|_M\ge r_B+r_S+g,
\qquad g>0.
\]

这样，同一个局部区域不会同时被要求执行两个不相容的更新规则。

然后给桥邻域定义目标：

\[
\boxed{
\mathcal U_Q(z;x)
=
q_{j+1}+\kappa(z-q_j),
\qquad z\in\mathcal B_j,\quad 0\le\kappa<1.
}
\]

假设学生实际状态是：

\[
z=q_j+\delta.
\]

那么希望它下一步到达：

\[
\boxed{
q_{j+1}+\kappa\delta.
}
\]

这个目标同时做两件事：

1. 从第\(j\)阶段前进到第\(j+1\)阶段；
2. 缩小偏离教师路径的误差\(\delta\)。

例如\(\kappa=\tfrac12\)时，目标会将偏差缩小一半，同时保留中心之间的前进。

对于后续计算邻域，则使用旧网络本身作为目标：

\[
\boxed{
\mathcal U_Q(z;x)=T_{\bar\theta}(z;x),
\qquad z\in\bigcup_k\mathcal V_k.
}
\]

完整目标就是：

\[
\boxed{
\mathcal U_Q(z;x)=
\begin{cases}
q_{j+1}+\kappa(z-q_j),&z\in\mathcal B_j,\\
T_{\bar\theta}(z;x),&z\in\bigcup_k\mathcal V_k.
\end{cases}
}
\]

**训练时用索引选择监督目标；部署网络不接收\(j\)、教师点或路径编号。** 我们希望它只根据当前状态和输入，学会对应更新。几何分离使监督关系一致，但不保证网络一定能学会。

**6．这些修复路径怎样找到？会不会变成“抄答案”？**

训练时允许使用标签\(y\)，优化桥变量\(v,U_j\)，而此时固定网络参数\(\bar\theta\)。

令后续计算长度为：

\[
L_s=H-m+S.
\]

教师搜索目标包括：

\[
\boxed{
\mathcal J_Q=
\underbrace{
\frac1{S+1}\sum_{s=0}^{S}
\ell\!\left(D(w_{H-m+s}),y\right)
}_{\text{真实续算的末端任务损失}}
+
\underbrace{
\frac{\lambda}{m}\sum_{j=0}^{m-1}
\|q_{j+1}-T_{\bar\theta}(q_j;x)\|_M^2
}_{\text{桥与现有更新的差距}}
+
\underbrace{\nu\mathcal P_{\rm clear}}_{\text{邻域间隔惩罚}}.
}
\]

第二项避免教师路径任意偏离现有网络能力；第三项鼓励满足前面的几何约束。

搜索使用预先声明的有限初始方向和优化步数。最后必须显式检查：

- 几何约束是否满足；
- 相对原轨迹是否有任务改善；
- 末端窗口是否正确且具有正分类余量；
- 后续计算对所检查的小扰动是否过于敏感。

惩罚小不能代替这些检查，也不保证搜索总能成功。

关于答案使用，边界是：

| 分支 | 标签如何使用 |
|---|---|
| 教师搜索 | 可以利用答案优化训练用隐藏状态 |
| 辅助邻域训练 | 可以读取标签参与构造的教师状态 |
| 学生真实续算 | 从模型自产状态出发，不把教师状态插入轨迹 |
| 实际推理 | 只输入问题和自身状态，没有答案、教师或修复路径 |

因此，它属于**利用训练监督学习更新规律**。但仍然可能过拟合教师状态，必须用未见样本和自由运行结果验证泛化。

**7．怎样真正更新共享网络？**

先对桥邻域训练：

\[
\boxed{
\widehat{\mathcal L}_B
=
\sum_{j=0}^{m-1}
\max_{\delta\in\mathcal A_j}
\left\|
T_\theta(q_j+\delta;x)
-
\left(q_{j+1}+\kappa\delta\right)
\right\|_M^2.
}
\]

\(\mathcal A_j\)是通过有限扰动搜索得到的点集，包含中心。这里的最大值只针对这些点，**没有求出整个邻域的真实最坏情况**。

同时，学生必须从原失败状态连续运行：

\[
u_0=\operatorname{sg}(a),
\qquad
u_{k+1}=T_\theta(u_k;x),
\]

\[
\boxed{
\mathcal L_{\rm real}
=
\frac1{S+1}
\sum_{s=0}^{S}
\ell(D(u_{H+s}),y).
}
\]

其中\(\operatorname{sg}\)表示停止梯度。

最终提议损失为：

\[
\boxed{
\mathcal L_{\rm proposal}
=
\mathcal L_{\rm real}
+
\beta_B\mathbf1[\text{找到合格走廊}]
\widehat{\mathcal L}_B.
}
\]

教师搜索失败时，第二项为零，第一项继续训练。

梯度处理也明确区分：

- 教师路径、搜索得到的扰动点，在参数学习前停止梯度；
- 学生从\(a\)出发的连续rollout正常反传；
- 不穿过教师优化过程求超梯度；
- 不需要高阶导数。

**这是从旧参数产生的anchor继续训练，不等于新参数从原始初始化运行时必然到达同一个anchor。** 这个分布变化是当前理论尚未解决的缺口之一。

**8．为什么还要在参数更新后检查一次？**

这是SGRL-v2很关键的一步。

同一个\(\theta\)既负责：

- 把失败状态带到有效区域；
- 在有效区域执行后续计算。

如果更新参数只顾学会前半段，可能破坏后半段。于是教师路径原本成立的依据就消失了。

我们先生成候选参数：

\[
\boxed{
\theta_b
=
\bar\theta-\alpha_0\rho^b
\nabla_\theta\mathcal L_{\rm proposal},
\qquad 0<\rho<1.
}
\]

然后检查有效后续计算邻域：

\[
\boxed{
\left\|
T_{\theta_b}(w_k+\delta;x)
-
T_{\bar\theta}(w_k+\delta;x)
\right\|_M
\le\bar\epsilon_S.
}
\]

同时要求：在相同探针集合和实际学生续算上，候选目标有所下降。

接受第一个满足条件的候选步；否则缩小步长继续检查。全部失败则该批次不更新参数。

为什么不直接加一个保持旧模型的正则就结束？

因为在更新前：

\[
T_\theta=T_{\bar\theta},
\]

所以正则

\[
\|T_\theta(z)-T_{\bar\theta}(z)\|^2
\]

及其参数梯度在这个起点都是零。它不能约束这一次更新将造成的偏移。因此，当前方案直接检查**更新之后的模型**。

这些仍然是有限探针检查，不是全局保留保证。每次接受更新后，旧教师和状态被丢弃，下一批重新收集。

**9．理论依据究竟支持到哪里？**

在桥邻域中，假设新网络对目标规则的统一误差满足：

\[
\sup_{z\in\mathcal B_j}
\left\|
T_{\rm new}(z)
-
[q_{j+1}+\kappa(z-q_j)]
\right\|_M
\le\epsilon_{B,j}.
\]

令学生与教师点的距离为：

\[
E_j=\|z_j-q_j\|_M.
\]

那么：

\[
\boxed{
E_{j+1}\le\kappa E_j+\epsilon_{B,j}.
}
\]

若从\(a=q_0\)出发，且各步误差不超过\(\epsilon_B\)，则：

\[
\boxed{
E_j\le
\epsilon_B\frac{1-\kappa^j}{1-\kappa}.
}
\]

这解释了为什么邻域目标可能控制误差积累。

进入原生后续计算后，如果旧映射的局部Lipschitz常数为\(L_k\)，新旧映射偏差不超过\(\epsilon_{S,k}\)，则：

\[
\boxed{
E_{m+k+1}
\le
L_kE_{m+k}+\epsilon_{S,k}.
}
\]

只要误差预算始终没有超出对应邻域，并且教师的正确类别余量足够大：

\[
\boxed{
\gamma_k>G_DE_{m+k},
}
\]

就可以推出该观察点的预测仍然正确。这里\(G_D\)衡量隐藏误差最多会改变多少输出类别余量。

**这些是有条件的有限步结论。** 它们没有证明：

- 有限搜索一定找到有效桥；
- 有限探针能验证整个邻域；
- 学到的网络处处收缩；
- 新参数下的自然轨迹必然进入该走廊；
- 所有未来loop都保持正确。

**10．推理时究竟发生了什么？**

推理代码仍然很简单：

```python
# theta 在整个推理过程中固定
z = initialize_without_answer(x)

for _ in range(K):
    z = shared_transition(z, x)

prediction = output_head(z)
```

没有“发现错误后调用教师”的步骤，也没有查找保存的修复路径。

修正能力应当体现在训练后的映射本身。例如，旧网络可能在错误状态停滞：

\[
T_{\rm old}(a;x)=a.
\]

修复监督要求：

\[
T_{\rm new}(a;x)\approx q_1,
\qquad q_1\ne a.
\]

**训练改变了这个状态附近的更新方向。** 如果这种变化能够泛化到真实推理遇到的相似状态，模型就可能摆脱原来的失败轨迹。

这才是“把修复学进共享网络”的具体含义。

**11．怎样接到LLM？**

需要区分两个索引：

- \(n\)：文本中的token位置；
- \(t\)：生成下一个token之前的内部递归深度。

当前语言定义为：

\[
\boxed{
z_{n,t+1}
=
T_\theta
\left(
z_{n,t};
E(x_n),\mathcal C_{<n},n
\right),
}
\]

\[
p(x_{n+1}\mid x_{\le n})
=
\operatorname{softmax}(D(z_{n,K})).
\]

\(\mathcal C_{<n}\)是已经提交的前缀缓存。

为了保持同一token内的递归映射不随深度变化，当前方案规定：

- 先前token保存各自**最后一次真实网络调用**产生的KV；
- 当前token的所有loop读取同一份前缀KV；
- 当前token只有最后一次调用的KV进入已提交缓存；
- 已输出的文本不被撤回。

这使“状态邻域对应同一更新规则”的训练原则可以接入因果语言模型。

但它有明确代价：**这是需要专门训练的缓存约定，不能直接当作普通Transformer缓存的等价替换。** Prefill存在逐token依赖；训练时每次候选参数更新还需要重建相应前缀，成本可能很高。

更重要的是，当前版本主要修复**生成下一个token之前的内部状态**。它没有自动获得撤回先前错误句子、重写整个推理草稿的能力。固定前缀上的恢复改善，也必须进一步验证能否提高整题自由生成正确率。

**12．为什么目前是445，而不是已经过线？**

| 维度 | 当前分数 | 主要依据与缺口 |
|---|---:|---|
| 问题价值 | **4** | 共享递归中的目标冲突、误差积累和续算破坏有研究价值，但尚未证明它们是主要实际瓶颈 |
| 方法质量 | **4** | 数学与训练流程具体；但有效教师、可学习邻域和可接受参数更新能否同时大量存在，仍未建立 |
| 问题匹配 | **5** | 三个机制分别直接处理它所提出的三个问题 |

它最有吸引力的地方是：**可能用额外训练成本，换取部署时不增加网络和单轨迹loop预算的恢复能力。**

最需要验证的是：这种训练能否在自然失败状态上带来收益，并胜过同教师、同总训练成本的一跳编辑器、普通路径模仿和更长常规训练。当前445是构想评分，尚不足以证明创新过线或LLM效果。
